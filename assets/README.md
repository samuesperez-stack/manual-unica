# Recursos Gráficos Oficiales — Assets
## Unión y Cambio (ÚNICA)

Esta carpeta contiene los archivos gráficos y plantillas de la organización:

- `logos/`: Archivos vectoriales en SVG, AI, EPS y PNG en alta resolución (fondo transparente).
- `fonts/`: Enlaces directos y guías para la instalación de las familias tipográficas oficiales (*Montserrat*, *Inter*, *Plus Jakarta Sans*).
- `templates/`: Plantillas base para Photoshop, Illustrator, Canva y Figma para publicaciones de redes sociales, notas de prensa y diapositivas de presentaciones.
