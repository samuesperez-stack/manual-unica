# Manual de Marca — Unión y Cambio (ÚNICA)
### Identidad Visual y Estrategia de Comunicación Política | Venezuela 🇻🇪

Bienvenido al repositorio oficial del **Manual de Marca de Unión y Cambio (ÚNICA)**, organización política comprometida con la reconstrucción democrática, la cohesión social y el futuro de Venezuela.

Este espacio está concebido como la **fuente de verdad única** para diseñadores, creativos, coordinadores de campaña regional y equipos de comunicaciones, garantizando coherencia visual, rigor técnico y contundencia en cada mensaje emitido tanto en plataformas digitales como en el territorio nacional.

## 🛠️ Lineamientos para Contribuir

1. **Formatos Vectoriales**: Todo material final para impresión o logotipos debe subirse en formato `.svg` o vector abierto en `assets/logos/`.
2. **Uso de Versiones Oficiales**: Queda prohibido alterar colores, deformar proporciones o aplicar sombras/efectos no autorizados en el logotipo.
3. **Flujo de Trabajo Git**:
   - Crear una rama (`git checkout -b feature/nombre-recurso`).
   - Realizar los cambios correspondientes y documentar los aportes.
   - Solicitar Pull Request para revisión del equipo nacional de comunicaciones.
